01 / ORIGINAL PAPER

回到 1992 年：
REINFORCE 解决什么问题？

当网络包含随机决策单元、只能从环境获取奖励信号时，怎样调整权重，使期望奖励增加？

MACHINE LEARNING · 1992VOL. 8 · PP. 229–256

Simple Statistical Gradient-Following Algorithms for Connectionist Reinforcement Learning

Ronald J. Williams · May 1992

原论文讨论包含随机单元的连接主义网络，提出一类 REINFORCE 权重更新规则，并论证其在即时奖励以及某些受限的延迟奖励任务中，平均更新方向与期望奖励的梯度相关。

ORIGINAL UPDATE RULE · SECTION 4
\Delta w_{ij}=\alpha_{ij}(r-b_{ij})e_{ij}
e_{ij}=\frac{\partial\log g_i}{\partial w_{ij}}
原论文中的 \(g_i\) 是随机单元输出的概率；现代策略中的对应对象是 \(\pi_\theta(a\mid s)\)。原论文 DOI ↗

NOW / POLICY GRADIENT

参数化策略

\pi_\theta(a\mid s)

表示智能体在给定状态下，选择某个动作的概率。

↗

共同的数学结构：利用“采样结果的对数概率梯度 × 奖励信号”估计期望回报的上升方向。REINFORCE 不需要对环境的状态转移求导。

04 / MATHEMATICAL DERIVATION

随机采样，为什么
仍然能提供梯度？

关键并不是直接对环境奖励求导，而是将概率分布的梯度改写为可采样的期望。

THE LOG-DERIVATIVE TRICK
\boxed{\nabla_\theta p_\theta(x)=p_\theta(x)\nabla_\theta\log p_\theta(x)}

又称 score-function identity。它将“概率分布的梯度”变成“概率 × 对数概率梯度”。

01 / OBJECTIVE

从单步期望奖励出发

假设奖励 \(r(s,a)\) 不显式依赖策略参数 \(\theta\)：

J(\theta)=\sum_a\pi_\theta(a\mid s)r(s,a)
\nabla_\theta J=\sum_a r(s,a)\nabla_\theta\pi_\theta(a\mid s)
02 / TRANSFORM

代入对数微分恒等式

\nabla_\theta\log\pi_\theta(a\mid s)=\frac{\nabla_\theta\pi_\theta(a\mid s)}{\pi_\theta(a\mid s)}
\nabla_\theta J=\sum_a\pi_\theta(a\mid s)r(s,a)\nabla_\theta\log\pi_\theta(a\mid s)
03 / SAMPLING ESTIMATOR

把求和改写为采样期望

\boxed{\nabla_\theta J=\mathbb E_{a\sim\pi_\theta}[r(s,a)\nabla_\theta\log\pi_\theta(a\mid s)]}

无需枚举每个动作，只需按当前策略采样并观察对应奖励，即可得到期望梯度的无偏估计。

EXTEND TO FULL TRAJECTORIES

多步轨迹的概率因子分解

p_\theta(\tau)=\rho_0(s_0)\prod_{t=0}^{T-1}\pi_\theta(a_t\mid s_t)P(s_{t+1}\mid s_t,a_t)

若初始状态分布和环境转移概率不显式依赖 \(\theta\)，对轨迹概率取对数并求导，环境项就会消失：

\boxed{\nabla_\theta\log p_\theta(\tau)=\sum_{t=0}^{T-1}\nabla_\theta\log\pi_\theta(a_t\mid s_t)}

令 \(R(\tau)=\sum_{t=0}^{T-1}r_{t+1}\) 表示无折扣总回报，则：

\nabla_\theta J=\mathbb E_\tau\left[R(\tau)\sum_{t=0}^{T-1}\nabla_\theta\log\pi_\theta(a_t\mid s_t)\right]
无须知道环境转移概率的具体函数形式，也无须对环境本身反向传播。
05 / CREDIT ASSIGNMENT

Reward-to-Go：
奖励如何沿时间回传？

每个动作仅使用从该时刻开始的未来奖励，排除它无法改变的过去奖励。拖动最后一步奖励和折扣系数，观察三步轨迹的回报分配。

三步都可能得到最终奖励的强化信号；折扣系数越小，早期动作分得的回报越少。Reward-to-Go 仍不能精确判定每个动作对最终结果的因果贡献。

重要的折扣约定

当 \(\gamma=1\) 时，标准无折扣回合目标的 REINFORCE 估计为：

\widehat{\nabla J}=\sum_{t=0}^{T-1}G_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)

若目标严格定义为固定初始状态下的折扣回报 \(J=\mathbb E[\sum_t\gamma^t r_{t+1}]\)，对应的无偏估计还需要外层折扣：

\widehat{\nabla J}=\sum_{t=0}^{T-1}\gamma^tG_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)

不要将不同教材中使用不同目标定义的两种写法不加说明地混为一谈。

06 / VARIANCE REDUCTION

Baseline：
为什么减去基线仍然正确？

原论文的更新规则就包含基线。现代 REINFORCE 中，常用状态价值函数作为基线，减小梯度估计的波动。

ABOVE BASELINE
G_t-b(s_t)>0

高于参考水平

增强本次采样动作在相应状态下的概率。

EQUAL TO BASELINE
G_t-b(s_t)=0

等于参考水平

该样本对应的策略梯度更新为零。

BELOW BASELINE
G_t-b(s_t)<0

低于参考水平

降低本次采样动作在相应状态下的概率。

UNBIASED BASELINE / PROOF

动作无关的状态基线，其期望梯度贡献为零

对于不依赖当前动作、在计算策略梯度时作为常量处理的 \(b(s)\)：

\begin{aligned}\mathbb E_{a\sim\pi_\theta}[b(s)\nabla_\theta\log\pi_\theta(a\mid s)]&=b(s)\sum_a\nabla_\theta\pi_\theta(a\mid s)\\&=b(s)\nabla_\theta\underbrace{\sum_a\pi_\theta(a\mid s)}_{1}\\&=0\end{aligned}
\(\mathbb E[(G_t-b(s_t))\nabla\log\pi]=\mathbb E[G_t\nabla\log\pi]\)

适当选择基线通常能降低方差，但任意基线并不保证降低方差。现代实现常使用 \(b(s_t)=V^\pi(s_t)\)，并定义采样优势估计 \(A_t=G_t-V^\pi(s_t)\)。

reinforce.py PYTORCH · γ = 1
import torch


def reinforce_update(log_probs, rewards, optimizer):
    """One complete episode; undiscounted REINFORCE."""
    # 1. Reward-to-Go, computed backwards
    returns = []
    G = 0.0
    for reward in reversed(rewards):
        G = reward + G
        returns.append(G)
    returns.reverse()

    # 2. Match tensor dtype/device, keep action log-prob graphs
    returns = torch.tensor(
        returns,
        dtype=log_probs[0].dtype,
        device=log_probs[0].device,
    )
    log_probs = torch.stack(log_probs)

    # 3. Minimize the negative policy-gradient objective
    loss = -(log_probs * returns).sum()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    return loss.item()
−

为什么损失前要加负号？REINFORCE 对期望回报做梯度上升，而 PyTorch 常用优化器对损失做梯度下降：\(\max J(\theta)\Longleftrightarrow\min[-J(\theta)]\)。这段核心函数假设已收集到一整回合的 log_probs 与 rewards。

01 / VARIANCE

Monte Carlo 估计方差大

轨迹回报会随随机动作和环境结果波动。可使用状态价值基线、TD 误差与 GAE 等方式估计优势。

02 / UPDATE TIMING

完整回合的更新等待较长

经典回合式 REINFORCE 需要等待未来奖励。Actor-Critic 可以通过价值函数和多步 bootstrap 估计未来回报。

03 / UPDATE SIZE

没有内建的策略变化约束

单次较大的梯度可能导致策略概率明显变化。PPO 引入新旧策略的概率比率与裁剪目标，限制超出区间后的目标收益。

THE CONNECTION
\underbrace{\nabla_\theta\log\pi_\theta(a_t\mid s_t)}_{\text{policy gradient}}\quad\longrightarrow\quad\underbrace{\min\!\left(r_t(\theta)\hat A_t,\operatorname{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat A_t\right)}_{\text{PPO clipped objective}}

PPO 的目标不是保证任意一次参数更新都提高真实回报，而是利用概率比率和裁剪机制控制优化目标对较大策略变化的鼓励程度。

09 / THE CORE THEOREM

最后，回到论文的
关键数学结论

单次采样的更新可以很噪声，但符合论文假设时，平均更新方向能够与期望奖励梯度一致。

WILLIAMS 1992 · THEOREM 1 · SECTION 4
\boxed{\mathbb E[\Delta W\mid W]=\alpha\nabla_W\mathbb E[r\mid W]}

当全部参数采用相同的正常数学习率 \(\alpha\)，且满足论文提出的相应条件时，平均更新等于期望奖励的梯度乘以学习率。对于更一般的非负学习率因子，论文给出平均更新与梯度的内积非负的结论。

ONE EQUATION TO REMEMBER
\boxed{\nabla_\theta J(\theta)=\mathbb E_\tau\!\left[R(\tau)\nabla_\theta\log p_\theta(\tau)\right]}

让环境提供奖励，让策略提供梯度。

这正是 REINFORCE 的思想起点，也是理解现代策略梯度算法、优势估计、Actor-Critic 和 PPO 的基础。
