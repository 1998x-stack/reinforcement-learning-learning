THE CORE IDEA

提高策略回报，同时限制“过度改变策略”所带来的代理收益。

\[L^{\mathrm{CLIP}}(\theta)=\hat{\mathbb E}_t\!\left[\min\left(r_t(\theta)\hat A_t,\;\operatorname{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat A_t\right)\right]\]

裁剪不是强制动作概率比率进入区间，而是改变代理目标的形状。在动态曲线中验证 ↗

01 / FOUNDATIONS

从 MDP 到策略梯度

先明确要优化的对象，再理解为什么奖励能够产生对策略参数的学习信号。

马尔可夫决策过程

\[\mathcal M=(\mathcal S,\mathcal A,P,R,\gamma,\rho_0)\]

给定状态 \(s_t\)，策略 \(\pi_\theta(a_t\mid s_t)\) 采样动作；环境返回奖励 \(r_t\) 与下一个状态。\(\gamma\) 控制远期奖励的权重。

状态 sₜ
→
策略 πθ
→
动作 aₜ
奖励 rₜ + 下一状态
←
环境 P

最大化长期回报

\[G_t=\sum_{k=0}^\infty\gamma^k r_{t+k}\]
\[J(\theta)=\mathbb E_{\tau\sim p_\theta}\!\left[\sum_{t=0}^\infty\gamma^t r_t\right]\]

目标不是贪心地最大化某一步奖励，而是提高当前策略生成轨迹的期望累计回报。

对数导数技巧 → 策略梯度

\[p_\theta(\tau)=\rho_0(s_0)\prod_{t=0}^{T-1}\pi_\theta(a_t\mid s_t)P(s_{t+1}\mid s_t,a_t)\]
\[\nabla_\theta\log p_\theta(\tau)=\sum_{t=0}^{T-1}\nabla_\theta\log\pi_\theta(a_t\mid s_t)\]
\[\nabla_\theta J(\theta)=\mathbb E_\tau\!\left[\sum_{t=0}^{T-1}\gamma^tG_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\right]\]

这里假设初始状态分布和环境转移不依赖策略参数，且 \(G_t\) 为从第 t 步开始的折扣回报。有些文献会把 \(\gamma^t\) 吸收到折扣状态访问分布中。

状态价值、动作价值与优势

\[V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s]\]
\[Q^\pi(s,a)=\mathbb E_\pi[G_t\mid s_t=s,a_t=a]\]
\[A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)\]

优势描述“这个动作比当前策略在相同状态下的平均表现好多少”。使用与动作无关的基线能够保留期望梯度，并有助于降低方差。

优势函数直觉

若当前状态价值 \(V^\pi(s)=10\)，动作 A 的 Q=15，动作 B 的 Q=7：

动作 AÂ = +5相对有利，提高其概率
动作 BÂ = −3相对不利，降低其概率

这里不应把“奖励高”与“优势一定为正”等同：优势取决于状态价值基准。

02 / ACTOR–CRITIC & GAE

一条轨迹如何转化为优势信号？

Actor 负责动作分布，Critic 提供价值参考；GAE 在一步 TD 与长期回报之间分配信息。

ACTOR · θ

策略网络

\[a_t\sim\pi_\theta(\cdot\mid s_t)\]

输出离散动作概率或连续动作分布，由 PPO-Clip 目标进行策略优化。

CRITIC · φ

价值网络

\[V_\phi(s_t)\approx\mathbb E[G_t\mid s_t]\]

提供价值基线，辅助构造优势估计与价值函数回归目标。

GAE：广义优势估计

\[\delta_t=r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t)\]
\[\hat A_t^{\mathrm{GAE}(\gamma,\lambda)}=\sum_{l\geq0}(\gamma\lambda)^l\delta_{t+l}=\delta_t+\gamma\lambda\hat A_{t+1}\]

\(\lambda=0\) 时仅使用一步 TD；\(\lambda=1\) 时累积后续 TD 误差。在真实终止且末端价值为零的有限轨迹上，后一种情况等于 Monte Carlo 回报减去价值基线；非终止截断则仍须 Bootstrap。

03 / FROM TRPO TO PPO

为什么需要限制策略更新？

一次过大的更新可能使新策略进入旧数据没覆盖的状态，旧数据代理收益并不等于新策略真实回报。

TRPO · TRUST REGION

KL 信赖域

\[\max_\theta\;\hat{\mathbb E}_t[r_t(\theta)\hat A_t]\]
\[\mathrm{s.t.}\;\hat{\mathbb E}_t[D_{\mathrm{KL}}(\pi_{\mathrm{old}}\Vert\pi_\theta)]\leq\delta\]

TRPO 通过 KL 约束限制策略分布变化；PPO 希望采用更简单的一阶优化方式实现类似的更新控制。

IMPORTANCE SAMPLING

为什么出现概率比率？

\[r_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\mathrm{old}}(a_t\mid s_t)}\]
\[L^{\mathrm{PG}}(\theta)=\hat{\mathbb E}_t[r_t(\theta)\hat A_t]\]

比率修正给定状态的动作概率，但不会自动修正新旧策略之间的状态访问分布偏移。这里是局部代理目标。

ε=0.2 不意味着每一个动作概率比率都被强制限制在 [0.8,1.2]，也不保证 KL 散度有硬上界，更不保证每次更新都提升真实回报。

05 / ASYMMETRIC OPTIMIZATION

为什么是 min，而不是直接 clip？

直接裁剪会掩盖策略朝不利方向变化的后果；min 保留原始目标的下降，只限制过度改善带来的收益。

EXPERIMENT A

好动作概率下降过多

\[\hat A=+1,\;r=0.5,\;\epsilon=0.2\]
原始目标0.50
直接裁剪0.80
PPO 取 min → 0.50

直接裁剪会把较差的结果隐藏为较高的目标；min 保留原始目标的不利变化。

EXPERIMENT B

差动作概率增加过多

\[\hat A=-1,\;r=1.5,\;\epsilon=0.2\]
原始目标−1.50
直接裁剪−1.20
PPO 取 min → −1.50

差动作变得更常被选择时，min 同样保留未裁剪目标的恶化趋势。

\[L_t^{\mathrm{CLIP}}\leq r_t\hat A_t\]

这是相对于未裁剪代理目标的逐样本下界，不是环境真实回报的全局下界。原论文 Figure 2 展示了沿实际更新方向移动时，批量目标与 KL 的变化。

06 / ALGORITHM 1

完整训练回路

当前策略采样 → 计算优势 → 固定旧统计量 → 多轮小批量优化 → 重新采样。

01 / ROLLOUT

用当前策略收集数据

\[\pi_{\theta_{\mathrm{old}}}\longrightarrow\mathcal D_k\]

记录状态、动作、奖励、旧动作对数概率、旧价值预测和终止/截断标志。

↓
02 / ADVANTAGE

计算并固定优势与价值目标

\[\hat A_t=\delta_t+\gamma\lambda\hat A_{t+1},\quad\hat R_t=\hat A_t+V_{\phi_{\mathrm{old}}}(s_t)\]

同一批次的旧 log-prob、优势及价值目标在重复优化期间保持不变。

03 / OPTIMIZATION

对同批数据训练 K 个 Epoch

EPOCH 1B1B2B3B4
EPOCH 2B3B1B4B2
EPOCH KB2B4B1B3

每个小批量重新计算当前策略 log-prob、比率、价值和熵；必要时根据近似 KL 提前停止后续更新。

04 / REFRESH

以新策略重新采样

\[\theta_{\mathrm{old}}\leftarrow\theta\]

PPO 是 On-Policy：可以重复使用当前批次，但一般不长期回放历史策略的数据。

时间截断不等于真实终止

\[\delta_t=r_t+\gamma(1-\mathrm{terminated}_t)V(s_{t+1})-V(s_t)\]

对外部截断使用截断前真实最终状态做 Bootstrap；GAE 不应越过环境重置连接到下一回合。固定 Rollout 在非终止状态结束时也要正确处理末端价值。

07 / LOSS & PYTORCH

从论文最大化目标到可执行损失

论文使用最大化目标；PyTorch 通常最小化负的策略代理目标。Actor、Critic 可共享主干，也可以采用独立网络。

ACTOR

策略损失

\[\mathcal L_\pi=-L^{\mathrm{CLIP}}\]

最大化保守裁剪的代理收益。

CRITIC

价值损失

\[\mathcal L_V=\tfrac12\mathbb E[(V_\phi(s)-\hat R)^2]\]

拟合采样构造的价值目标。

EXPLORATION

策略熵

\[H(\pi)=-\sum_a\pi(a\mid s)\log\pi(a\mid s)\]

通过适当奖励维持一定随机性。

联合损失 · 最小化形式

\[\mathcal L_{\mathrm{total}}=\mathcal L_\pi+c_v\mathcal L_V-c_e\mathbb E_t[H_t]\]

原论文另提出 PPO-Penalty：\(L^{\mathrm{KLPEN}}=\hat{\mathbb E}_t[r_t\hat A_t-\beta D_{\mathrm{KL}}(\pi_{\mathrm{old}}\Vert\pi_\theta)]\)。它用 KL 惩罚替代裁剪，但不构成硬约束。

REFERENCE IMPLEMENTATION

PyTorch · PPO-Clip 小批量核心

import torch

def ppo_step(actor, critic, optimizer, batch,
             eps=0.2, value_coef=0.5,
             entropy_coef=0.01, max_grad_norm=0.5):
    obs, actions = batch["obs"], batch["actions"]
    old_logp = batch["old_logp"].detach()
    adv = batch["advantages"].detach()
    targets = batch["returns"].detach()

    if adv.numel() > 1:
        adv = (adv - adv.mean()) / (
            adv.std(unbiased=False) + 1e-8)

    dist = actor(obs)
    # log_prob(actions) is assumed to have shape [B]
    # For independent continuous actions sum across action dims.
    new_logp = dist.log_prob(actions)
    values = critic(obs).reshape(-1)
    ratio = torch.exp(new_logp - old_logp)

    s1 = ratio * adv
    s2 = torch.clamp(ratio, 1 - eps, 1 + eps) * adv
    policy_loss = -torch.minimum(s1, s2).mean()
    value_loss = 0.5 * (values - targets).square().mean()
    entropy = dist.entropy().mean()

    loss = (policy_loss + value_coef * value_loss
            - entropy_coef * entropy)
    optimizer.zero_grad()
    loss.backward()
    params = list(actor.parameters()) + list(critic.parameters())
    torch.nn.utils.clip_grad_norm_(params, max_grad_norm)
    optimizer.step()
    return {"policy_loss": policy_loss.item(),
            "value_loss": value_loss.item(),
            "entropy": entropy.item()}

演示代码假设 Actor 和 Critic 参数不重复、动作维度已正确归约。完整训练仍需 Rollout/GAE、准确处理 truncated/terminated、KL 监控以及按任务选择网络和动作分布。

08 / TRAINING STABILITY

如何判断 PPO 真的在学习？

参考配置是经典控制任务的实验起点，不是跨任务的最优参数。

基线超参数

学习率3×10⁻⁴
折扣 γ0.99
GAE λ0.95
裁剪 ε0.20
Rollout 总步数2048
Minibatch64
Epoch10
梯度范数上限0.5

Episodic Return

查看独立评估回报和不同随机种子的波动，避免仅根据策略损失判断表现。

Approximate KL / Clip Fraction

KL 估计新旧策略偏离；Clip Fraction 是比率超出裁剪区间的样本占比，不等于零梯度样本占比。

Value Loss / Explained Variance

诊断 Critic 拟合能力。不同环境的奖励尺度不同，价值损失绝对数值不可直接横向比较。

Policy Entropy / Advantage

观察策略随机性与优势分布；熵下降不必然等于训练失败，需联合评估回报。

排查方向

回报骤降：共同检查学习率、Epoch、KL 和优势估计；价值损失异常：检查奖励尺度、末端 Bootstrap 与目标构造；不同随机种子差异大：报告平均值及波动范围。

09 / LIMITATIONS & EXPERIMENTS

从使用 PPO 到研究 PPO

裁剪机制不消除状态分布偏移、样本效率和实现细节等问题。

QUESTION 01

代理收益与真实回报之间的距离

\[d_{\mathrm{old}}(s)\ne d_{\mathrm{new}}(s)\]

比较训练 KL、裁剪代理目标与独立评估回报，分析分布偏移时的表现。

QUESTION 02

固定 ε 是否适合整个训练阶段？

研究按 KL 和 Clip Fraction 动态调整 ε，并在同等交互预算下比较回报与波动；自适应本身不保证改善。

QUESTION 03

GAE 与 Critic 误差如何耦合？

对 λ∈{0,0.5,0.8,0.95,1} 做消融实验，记录优势方差、价值误差、回报和跨种子的差异。

QUESTION 04

实现细节是否改变实验结论？

分别控制优势标准化、梯度裁剪、网络初始化、价值裁剪和奖励处理，避免误把工程差异当作算法改进。

可复现实验：裁剪系数消融

控制变量网络、学习率、γ、λ、Epoch 和随机种子集合
自变量ε ∈ {0.1, 0.2, 0.3}
观测量回报、KL、Clip Fraction、价值误差与耗时
目标识别样本效率与更新稳定性之间的任务依赖
